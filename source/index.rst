Documentation Portal
===========================================

This site collects the manuals for TurboRVB, TurboGenius, and TurboWorkflows.
Choose the entry point based on whether you want to run QMC calculations directly, use the main user-facing interface, or automate multi-step workflows.

   .. container:: manual-compare-item manual-compare-item--turborvb

         :alt: TurboRVB logo

      Use this when you want direct control over executables, input files, and low-level QMC details.
