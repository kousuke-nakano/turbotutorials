class LRDMC_ext_workflow

This class manages the workflow of LRDMC calculations with extrapolation of lattice parameter to zero.

Module usage

Description

In the LRDMC_ext_workflow class, the LRDMC extrapolation workflow is executed asynchronously (via async_launch()). The workflow runs LRDMC at multiple time step (alat) values and extrapolates the energy to the \(a \to 0\) limit using polynomial fitting.

The workflow:

  • For each value in lrdmc_alat_list, creates a subdirectory alat_{value}, copies lrdmc_input_files (e.g. fort.10, pseudo.dat) into it, and launches an LRDMC_workflow instance with that alat. All alat runs are launched concurrently with asyncio.gather().

  • After all runs complete, collects energies and errors from each alat directory, writes evsa.in and evsa.gnu, and runs funvsa.x to fit energy vs. \(a^2\) with a polynomial of degree degree_poly.

  • Reads the extrapolated energy and error (constant term) from evsa.out, stores them in output_values["energy"] and output_values["error"], and generates a plot Energy_vs_alat.png.

No pkl-based skip logic is applied at the top level; each inner LRDMC_workflow uses its own continuation and pkl state. On success, the method returns (status, list of output file paths under the root directory, and an output-values dict containing the extrapolated "energy" and "error").
