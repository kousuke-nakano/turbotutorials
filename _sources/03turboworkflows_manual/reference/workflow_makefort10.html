class Makefort10_workflow

This class manages the workflow of generating wavefunction template.

Module usage

Description

In the Makefort10_workflow class, the makefort10 workflow is executed asynchronously (via async_launch()). The workflow generates a fort.10 wavefunction file from a structure file using the makefort10.x binary with specified basis sets and Jastrow factors (no job submission; runs locally via Makefort10_genius.run_all()).

If the pkl file already exists and makefort10_rerun is False, the calculation is skipped. Otherwise, the workflow:

  • Builds a Makefort10_genius instance from the constructor parameters (structure file, supercell, basis sets, Jastrow type, phase, etc.) and calls run_all() to generate fort.10 and related files.

  • Persists state in a pkl file under the pkl directory.

On success, the method returns (status, list of output file paths under the root directory, and an empty output-values dict).
