view

Description

This command visualizes a molecule or crystal structure written in fort.10.

Synopsis

turbogenius view [OPTIONS]

turbogenius view --help

This command shows the list of available options.

Options

general option

This option affects all actions.

option

default value

description

-log TEXT

INFO

Specify log level. The argument is DEBUG, INFO, or ERROR.

Input and output files

  • input: fort.10

  • output: None(GUI)
