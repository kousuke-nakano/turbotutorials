Documentation Portal

This site collects the manuals for TurboRVB, TurboGenius, and TurboWorkflows. Choose the entry point based on whether you want to run QMC calculations directly, use the main user-facing interface, or automate multi-step workflows.

Which Manual Should I Use?

TurboGenius

Best starting point for most users running standard workflows from the CLI or Python.

TurboWorkflows

Use this when you need remote execution, queued jobs, or chained workflow automation.

TurboRVB

Use this when you want direct control over executables, input files, and low-level QMC details.
